# 持久任务与成果：第一阶段

日期：2026-10-10。

## 本轮范围

- 在现有 WorkflowCenter 中加入任务页，保留原收件箱、评审和交接。
- 主进程原子持久化 Task、TaskRun、Deliverable，独立于 renderer 和引擎会话。
- 创建任务时固定项目、worktree、子目录，执行前再次校验，不自动回退到其他目录。
- 人工创建执行草稿，不自动发送、不自动批准、不增加无人值守权限。
- 三引擎事件更新执行状态：一轮结束只进入待验收，用户明确确认后才完成。
- 文本成果和文件引用（哈希、大小）；文件引用不是文件备份。
- 重启后未完成的尝试标记中断，不自动重放有副作用的工作。
- 失败、中断或退回后可创建新尝试，保留历史成果及反馈。

## 不在本轮范围

Cron、无人值守执行、任务依赖图、远程控制、自动运行测试、文件快照备份、Office 编辑、多 Agent 自动协调。

## 安全与一致性

仅主窗口主 frame 可调用 IPC。主进程校验输入、项目删除屏障、工作区和版本。文件引用做 realpath 校验并拒绝越界。损坏任务库保留原文件；写失败不更新内存、不发出成功事件。历史尝试不能覆盖新尝试。导航不能覆盖未发送文字或附件。不迁移或删除原有 workflow localStorage 数据。

## 验证范围

存储、故障、重启、版本冲突、路径边界、引擎事件归一化和草稿导航使用模型无关测试；界面使用隔离 profile 冒烟；执行完整回归、类型检查和构建。真实供应商模型与跨平台安装包验收另列，不能由模拟事件代替。
