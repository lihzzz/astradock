# 任务工作台使用说明

## 创建与执行

1. 打开工作流中心的“任务”页，选择“新建任务”。
2. 选择项目和固定工作区，按需填写相对工作区的子目录。
3. 填写名称、目标和验收条件（每行一项）。
4. 选择执行 Agent，点击“准备执行草稿”。检查会话输入后自行发送。

创建任务、准备草稿都不会自动发送消息或批准工具执行。已有未发送文字或附件会阻止草稿导航，避免被覆盖。工作区不可用时不会自动换到其他目录。

## 成果与验收

执行结束后查看关联会话和实际文件，再记录文本验证报告或文件引用。文件引用保存相对路径、大小和 SHA-256，不是备份；文件变更或丢失时无法按原成果定位。

待验收时，至少记录一个成果并逐项确认验收条件，才能“验收通过”。需要修改时填写反馈并“退回修改”，之后手动准备下一次尝试。历史成果与反馈保留，已验收记录不随后续聊天轮次改写。

## 中断与恢复

程序重启后，未结束的尝试标记中断，不自动执行。失败或中断后先检查会话与文件，再决定是否重试。放弃未使用草稿只结束任务尝试记录，不停止 Agent，也不清空聊天输入。

关联会话尚未保存或已删除时，打开会话可能失败；这不代表任务记录或成果已删除。
